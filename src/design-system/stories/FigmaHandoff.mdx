## Convención de nombres

`TRAZA/Core/{Family}/{Component}/{Variant}` y `TRAZA/Patterns/{Pattern}/{State}`. Los tokens se exponen como `color/text/primary`, `space/4`, `radius/card`, `motion/base` y `layout/safe-bottom`.

## Component sets prioritarios

- Button: Primary / Secondary / Quiet / Danger × Rest / Pressed / Disabled.
- StatusBadge: Confirmed / Planned / Open / Saved / Researching / Evaluating.
- DayCover: Left / Back / Top × Day 06–13, con regiones `Kicker`, `Art`, `Number`, `Copy`, `Action`.
- Sheet: Default / Wide × Rest / Keyboard / Reduced motion.
- BottomNavigation: Journey / Saved / Trip.

## Auto-layout

Respeta el orden de anatomía de Storybook. Usa variables en lugar de estilos separados y documenta excepciones editoriales en la descripción del componente. Storybook y los tests de bounds son la referencia ejecutable.
