# Electric London working agreement

- Build a mobile-first trip companion, never a generic dashboard.
- Preserve Journey / Saved / Trip and keep anchors, intentions and nearby options distinct.
- Treat `docs/` and `03_SEED_DATA.json` as product truth. Keep data behind the repository boundary.
- Never surface private booking references or confirmation codes.
- Use strict TypeScript, small components, semantic HTML, visible focus and reduced-motion support.
- Update `docs/IMPLEMENTATION_PLAN.md` when scope or interaction decisions change.
- Before handoff run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
