# Content System

- Títulos: sentence case, concretos, máximo tres líneas en DayCover 402 px. Sin punto final salvo frase completa.
- Labels y acciones: verbo + objeto (`Añadir lugar`, `Guardar cambios`); no alternar sin motivo entre infinitivo y sustantivo.
- Estados fijos: Confirmado, Plan, Abierto, Guardado, Investigando, Evaluando. `anchor`, `intention` y `nearby-option` siguen siendo niveles distintos.
- Fechas: día de semana + número en contexto narrativo; fecha corta en logística. Nunca mostrar referencias privadas.
- Uppercase: solo eyebrow, metadata compacta y labels mono; no para párrafos ni titulares.
- Mono: horas, índices, progreso y datos breves; no contenido editorial.
- Ayuda: explica consecuencia, no implementación. Error: problema + siguiente acción, sin culpar.
- Vacío: estado real + acción posible; no inventar recomendaciones.
- Terminología: Días / Guardados / Viaje; “asignar” para colocar un guardado, “organizar” para reordenar.

El tono es directo, tranquilo y útil en movimiento. Esta iteración no reescribe el contenido del viaje.
