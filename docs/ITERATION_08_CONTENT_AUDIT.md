# Iteración 08 — auditoría de contenido

| Texto anterior | Diagnóstico | Decisión |
| --- | --- | --- |
| `VIE 07 · CAPÍTULO 02` | Código duplicado y decorativo | Sustituir por fecha natural + `2 / 8` |
| `07 AGO` junto a otra fecha | Redundante | Una sola fecha |
| `VIE / 07` | Código sin función | Eliminar |
| `Altura, piedra y cristal…` | Poético genérico | `Sky Garden por la mañana, la City al mediodía y Canary Wharf antes del musical.` |
| `Confirmado / Plan flexible / Opción cercana` permanente | Explica badges ya visibles | Eliminar del hero |
| `1 MOMENTO` | Técnico/artificial | `1 plan`; plural natural |
| `Banco de posibilidades` | Abstracto | Eliminar |
| `Guardados para decidir después…` | Repite el concepto | Dejar recuento `28 lugares` |
| `TRAZA / LONDRES 2026 / GUARDADOS` | Marca/contexto duplicado | `Londres 2026`, `Guardados`, recuento |
| Tags completos en uppercase | Ruido | Máximo dos y `+N` |

Se conservan los títulos de día, nombres de secciones y rutas breves porque aportan orientación y personalidad editorial.
