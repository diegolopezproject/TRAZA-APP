# Decisiones de patrón TRAZA

| Decisión | Elegida | Motivo | Trade-off |
|---|---|---|---|
| Navegación | Días / Guardados / Viaje | Conserva el modelo mental validado | Organizar es estado contextual, no cuarto destino |
| Cabecera | símbolo TRAZA + Londres 2026 + Día n de 8 + fecha | Orienta en una mirada | Consume una línea vertical en móvil |
| Portadas | retícula segura y motivo semántico por día | Mantiene personalidad sin ruido | Menos libertad para collage irregular |
| Superficie | sólida por defecto; raised para plan; glass en capa funcional | Contraste, rendimiento y contexto | Requiere estados responsive adicionales |
| Tipografía | Geist Sans + mono para metadata | Ya está licenciada y cargada; lectura rápida | Menos contraste editorial que una serif |
| Organizar | borrador local + Guardar cambios | Cancelar es fiable y reversible | La previsualización no sincroniza hasta guardar |
| Drag | HTML drag desktop + controles mover arriba/abajo/sección | Accesible sin depender de touch | Menos “mágico” que un gesto puro |
| Media | editorial generado o fallback determinista etiquetado | Evita scraping y duplicados | Fallback no pretende ser fotografía documental |
