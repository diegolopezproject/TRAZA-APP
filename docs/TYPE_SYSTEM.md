# Type system

Se evaluaron dos direcciones:

- **A — Geist + Instrument Serif**: más editorial, pero añade dependencia y aumenta el contraste tipográfico en controles.
- **B — Geist Sans + Geist Mono (elegida)**: ya disponible, consistente en móvil y más rápida en una experiencia de lectura frecuente.

Reglas: Sans para títulos y cuerpo; Mono para fechas, horas, etiquetas y contadores. No hay serif en botones, formularios, horas ni navegación. Un acento editorial puede usar peso/espaciado, no una familia adicional.

Escala: display clamp(2.8rem, 10vw, 7rem), h1 2rem, h2 1.2rem, body 1rem/1.45, meta .7rem/1.1 mono. Los títulos de portada se limitan a la retícula segura para no cortarse.
