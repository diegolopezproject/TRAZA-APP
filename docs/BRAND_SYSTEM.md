# Sistema de marca TRAZA

TRAZA nombra el rastro que convierte planes dispersos en un viaje legible. La marca es contemporánea y flexible, pero nunca ocupa el espacio que pertenece al viaje.

## Tres niveles

| Nivel | Composición | Uso |
|---|---|---|
| 1 · Icono de aplicación | Símbolo aislado | Favicon, app icon y superficies extremadamente compactas |
| 2 · Marca compacta | Símbolo + TRAZA | Header contextual de Guardados y Viaje, documentación |
| 3 · Contexto del viaje | Londres 2026 + fecha/progreso | Portada del día o resumen de Viaje; no se obliga a convivir con el nivel 2 |

## Símbolo y wordmark

El símbolo sigue siendo una T geométrica abierta que sugiere una trayectoria. No es un pin, avión, bandera ni monograma temporal. El wordmark utiliza la sans principal; el SVG permanece para aplicaciones de marca amplias, no para repetirlo en cada hero.

## Reglas de uso

- Mínimo 24 px para el símbolo en UI y 48 px como icono aislado.
- Ink sobre Cloud o versión inversa; Lime solo como gesto de trayectoria/selección.
- Una pantalla puede mostrar nivel 1, 2 o 3; nunca necesita los tres.
- Días no muestra app bar: fecha, ciudad y progreso ya aportan contexto.
- Guardados y Viaje muestran marca compacta más una línea de contexto, no tagline.
- `TRAZA`, `Londres 2026`, tagline, sección y progreso no se apilan simultáneamente.
- Las referencias privadas no forman parte de la identidad ni de capturas públicas.
